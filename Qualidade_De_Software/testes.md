#### Teste de unidade
&emsp;Os testes de unidade tem como objetivo testar cada componente, classe ou objeto do sistema individualmente. O maior exemplo são os testes em métodos do sistema que chamam o método com determinado input e aguardam que o output esteja coerente com o esperado.

#### Teste de integração
&emsp;Testa os componentes do sistema como um todo para validar o comportamento deles entre si

#### Teste de validação
&emsp;Os testes em que requisitos estabelecidos como parte dos requisitos de modelagem são validados em relação ao software desenvolvido 

#### Teste de sistema 
&emsp;Testes em que o software e os outros elementos são testados como um todo.
